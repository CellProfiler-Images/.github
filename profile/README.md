## First Look at CellProfiler

CellProfiler is for people who keep microscopy images they own and want one named cell desk, not mixed untitled pipelines. It gives you own images, a pipeline list, and a short path back to an object view you already keep. It does not replace the rest of your PC.

## Inside CellProfiler

CellProfiler is a local Windows bioimage app with a named cell desk, a short pipeline list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside images you already own and holds only the pipeline that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra pipelines wait for their own title. CellProfiler starts with a local profile and does not need a complex account system.
